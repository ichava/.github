# ichava/.github

> Organization-wide community health files and the org profile for the
> [ichava](https://github.com/ichava) organization.

`profile/README.md` renders at [github.com/ichava](https://github.com/ichava) and
is the canonical org index — this file deliberately duplicates none of it. The
default `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, and `CODE_OF_CONDUCT.md`
here apply to every ichava repository lacking its own.

`profile/banner-light.svg` and `profile/banner-dark.svg` are the org banner. They
are referenced relatively from the profile README; GitHub rewrites those paths to
raw URLs on both `<img src>` and `<source srcset>`.
